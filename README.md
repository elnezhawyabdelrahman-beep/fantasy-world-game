# Fantasy World — The Shattered Isles

An offline-first 3D fantasy adventure built with TypeScript, Vite and Babylon.js.

## Play locally
```bash
npm install
npm run dev
``

## Validate
```bash
npm test
npm run build
``

## Current playable foundation
- Third-person 3D island with procedural trees, rocks, ancient ruins and a village keeper.
- Keyboard movement (WASD / arrows), mouse camera, touch joystick and action buttons.
- Collectible moon crystals, a guided opening quest, XP and player levels.
- Local IndexedDB save and restore.
- PWA manifest, service-worker caching and install prompt support.
- GitHub Actions build and test workflow.

## Controls
- Move: WASD / arrow keys or on-screen joystick
- Interact: E or the ✧ button near the Keeper or a crystal
- Camera: drag the screen / mouse
- Jump: on-screen arrow button

The project is designed to expand in small tested stages.
